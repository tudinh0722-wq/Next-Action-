# NextA Development Plan

## Completed foundation
- Flutter-first planner architecture.
- Month-first Calendar with month/week collapse and navigation.
- Selected-day Agenda.
- Event CRUD and local SQLite persistence/search.
- Material 3 semantic theming direction.
- Countdown policy and refresh strategy.
- Samsung Calendar-inspired Add Event editor.
- Priority persistence and shared severity presentation.
- Numeric reminder configuration and repeat metadata.
- Finite recurrence generation and recurrence controls.
- Recurrence unit tests.

## Remaining product work
- Series-aware recurrence edit/delete verification and edge cases.
- Replace AI Import placeholder with bulk import, preview, validation and persistence.
- Add bulk-import integration tests.
- Complete Android Home Widget and Focus/Lock Screen verification.
- Add/verify iOS platform adapters.
- Broader cross-device responsive verification.
- Final persistence/search/recurrence regression pass.
- Release-readiness cleanup and verification.

## UI lock
Calendar and Agenda are finished baseline screens. Their visual presentation must not change unless the user explicitly requests it.
